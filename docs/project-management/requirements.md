# 需求与验收标准

更新时间：2026-09-21

状态说明：代码状态、自动化状态、Windows 实机状态和发布状态分别在
[实现状态](implementation-status.md) 中维护。

## Overlay 与气泡

| ID | 需求 | 验收标准 | 规格来源 |
| --- | --- | --- | --- |
| REQ-UI-001 | 小猫右键菜单 | 仅猫咪命中；按状态显示“开启语音”或“关闭语音”，并含“退出” | 修订规格 2.5 |
| REQ-UI-002 | 500ms 长按拖动 | 500ms 内松开保持短按重试；达到阈值后拖动，释放后恢复业务动画 | 修订规格 2.1 |
| REQ-UI-003 | 多显示器拖动 | 使用虚拟桌面绝对坐标和实际工作区；左侧、上方副屏不镜像、不跳边 | 修订规格 3 |
| REQ-UI-004 | 动态气泡位置 | 四边放到相反侧，四角放到斜对角；重排不改变猫咪屏幕坐标 | 修订规格 2.3 |
| REQ-UI-005 | 自适应气泡宽度 | 短文本收缩；长文本最大有效宽度约 780px；不分页、滚动或缩字 | 修订规格 2.2 |
| REQ-UI-006 | 稳定换行 | 保留全部字符和段落；避免结束标点行首及末行仅剩 1～2 字 | 修订规格 4.2 |
| REQ-UI-007 | 推荐文本字重 | 推荐标题使用普通字重，标题后的内容使用粗体 | 修订规格 2.2 |

## 动态形象

| ID | 需求 | 验收标准 | 规格来源 |
| --- | --- | --- | --- |
| REQ-ANI-001 | 五种批准姿态 | 等待、启动挥手、推荐指向、失败、抓头使用批准素材，不含姓名或 Codex 宠物 | 修订规格 2.4 |
| REQ-ANI-002 | 状态动作 | 启动仅挥爪；OCR 与拖动复用抓头；推荐、失败动作符合状态语义 | 修订规格 5 |
| REQ-ANI-003 | 全状态眨眼 | 每个产品动画循环约 3 秒，并包含一次自然眨眼 | 修订规格 5.2 |
| REQ-ANI-004 | 安全回退 | 动画资源失效时使用正确的 GameBuddy 静态图，程序仍能启动运行 | 修订规格 2.4 |

## 语音陪伴

| ID | 需求 | 验收标准 | 规格来源 |
| --- | --- | --- | --- |
| REQ-VOICE-001 | 本地语音播报 | 气泡和当前业务事件转为简短、口语化摘要，不逐字朗读长文本 | 修订规格 6.1 |
| REQ-VOICE-002 | Windows 本地 TTS | 持久 PowerShell 子进程调用 `.NET System.Speech`，失败不影响主链路 | 修订规格 6.3 |
| REQ-VOICE-003 | 语音选择 | 配置语音优先，其次中文女性语音，最后使用 Windows 默认语音 | 修订规格 6.3 |
| REQ-VOICE-004 | 调度策略 | 支持优先级、过期、去重；高优先级可打断低优先级 | 修订规格 6.4 |
| REQ-VOICE-005 | 陪伴节流 | 低优先级陪伴播报间隔至少 60 秒 | 修订规格 6.4 |
| REQ-VOICE-006 | OCR 进度 | OCR 持续超过 2 秒才播报一次进度，提前结束则不播报 | 修订规格 6.4 |
| REQ-VOICE-007 | 语音开关 | 默认开启并持久化；关闭时停止播放并清理低优先级队列 | 修订规格 6.5 |
| REQ-VOICE-008 | 统一消息模型 | 本地消息与未来远端陪伴推送使用同一 `SpeechMessage` 模型 | 修订规格 6.2 |
| REQ-VOICE-009 | 远端接口边界 | 首版只预留远端适配接口，不连接远端服务或新增网络访问 | 修订规格 6.1 |
