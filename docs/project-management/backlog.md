## BK-VOICE-001 约束

未来远端陪伴消息必须先转换为现有 `SpeechMessage`，再进入同一去重、过期、
优先级和静音链路。远端适配器不能绕过 60 秒低优先级节流，也不能直接操作
PowerShell worker。

在实现前必须确认：

- 服务端地址、鉴权方式和用户授权范围。
- 消息 ID、去重键、优先级、创建时间和过期时间的来源。
- 断线重连、离线丢弃、隐私和日志脱敏规则。
- 与本地推荐、错误、OCR 进度发生冲突时的优先级。

## BK-VOICE-002 约束

只有在出现明确平台或音质需求后才增加新的 TTS 适配器。调度策略和
`SpeechMessage` 不应依赖具体 TTS 实现，现有 Windows 适配器继续作为无网络依赖的回退。
