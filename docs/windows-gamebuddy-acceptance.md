## 检查项

### 1. 右键菜单范围

- 准备：启动 GameBuddy，确认小猫显示。
- 操作：分别右键小猫、气泡、按钮外透明区域。
- 预期：只有右键小猫时出现菜单，菜单仅含“退出”。
- 实际：
- 结果：通过 / 不通过

### 2. 菜单收起与退出

- 准备：右键小猫打开菜单。
- 操作：先点击菜单外确认收起；再次打开后点击“退出”。
- 预期：点击外部只收起菜单；点击“退出”后 Overlay、轮询和视觉子进程全部结束，无二次确认。
- 实际：
- 结果：通过 / 不通过

### 3. 短按重试兼容

- 准备：进入允许手动重试识别的状态。
- 操作：左键短按小猫并在 500ms 内松开。
- 预期：窗口不移动，仍触发现有重新识别逻辑。
- 实际：
- 结果：通过 / 不通过

### 4. 500ms 长按拖动

- 准备：记录 Overlay 初始位置。
- 操作：分别按住不足 500ms、按住达到 500ms 后移动鼠标。
- 预期：不足 500ms 不拖动；达到 500ms 后整个 Overlay 平滑移动，气泡和按钮相对位置不变。
- 实际：
- 结果：通过 / 不通过

### 5. 显示器边界与位置重置

- 准备：如有多显示器，将各显示器设为不同排列，并保留任务栏。
- 操作：把小猫拖到当前显示器四边和角落，然后重启 GameBuddy。
- 预期：小猫始终完整可见；重启后恢复默认右上角位置。
- 实际：
- 结果：通过 / 不通过

### 6. 六种动画状态

- 准备：依次触发等待、首次显示、OCR 识别、观察新三选一、推荐成功和识别失败。
- 操作：每种状态至少观察两个循环，并切换到下一状态。
- 预期：对应显示闭眼呼吸、举手、挠头、歪头、点爪和耳朵下垂；切换及时且持续循环。
- 实际：
- 结果：通过 / 不通过

### 7. 拖动期间动画

- 准备：让小猫处于明显运动中的状态。
- 操作：长按进入拖动，保持两秒后松开。
- 预期：拖动期间小猫帧冻结，松开后继续当前业务状态动画；气泡和按钮不变形。
- 实际：
- 结果：通过 / 不通过

### 8. 气泡换行

- 准备：显示包含长玩法名、长装备列表、标点和多段说明的推荐。
- 操作：检查所有页的每一行，并切换不同窗口宽度或显示缩放。
- 预期：没有仅剩 1～2 个字符的末行，没有结束标点出现在行首，文字不丢失且不覆盖按钮。
- 实际：
- 结果：通过 / 不通过

### 9. 标题和内容字重

- 准备：显示正常推荐结果。
- 操作：检查“当前推荐”“当前玩法”“所需海克斯”“所需装备”四行。
- 预期：四个标题使用普通字重，标题后的值使用粗体；分页后仍保持正确字重。
- 实际：
- 结果：通过 / 不通过

- 预期：程序使用原静态小猫正常启动，识别、推荐、短按和退出功能可用，日志记录资源错误。
