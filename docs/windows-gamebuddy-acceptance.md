## 检查项

### 1. 正常启动

- 准备：安装 64 位 Windows、Python 3.11 和 Visual C++ 2015–2022 x64 运行库。
- 操作：双击根目录的 `一键启动小猫.cmd`。
- 预期：GameBuddy 正常启动并显示小猫，不修改 PowerShell 全局执行策略。
- 实际：
- 结果：通过 / 不通过

### 2. 右键菜单范围

- 准备：启动 GameBuddy，确认小猫显示。
- 操作：分别右键小猫、气泡、按钮外透明区域。
- 预期：只有右键小猫时出现菜单，菜单仅含“退出”。
- 实际：
- 结果：通过 / 不通过

### 3. 菜单收起与退出

- 准备：右键小猫打开菜单。
- 操作：先点击菜单外确认收起；再次打开后点击“退出”。
- 预期：点击外部只收起菜单；点击“退出”后 Overlay、轮询和视觉子进程全部结束。
- 预期：退出时不显示二次确认。
- 实际：
- 结果：通过 / 不通过

### 4. 短按重试兼容

- 准备：进入允许手动重试识别的状态。
- 操作：左键短按小猫并在 500ms 内松开。
- 预期：窗口不移动，仍触发现有重新识别逻辑。
- 实际：
- 结果：通过 / 不通过

### 5. 500ms 长按拖动

- 准备：记录 Overlay 初始位置。
- 操作：分别按住不足 500ms、按住达到 500ms 后移动鼠标。
- 预期：不足 500ms 不拖动；达到 500ms 后小猫跟随鼠标平滑移动。
- 实际：
- 结果：通过 / 不通过

### 6. 多显示器绝对坐标

- 准备：至少使用两块显示器，其中一块位于主屏左侧或上方，并保留任务栏。
- 操作：在各显示器之间来回拖动小猫，并拖到每块屏幕的边界。
- 预期：跨屏连续，负坐标不镜像；小猫不跳到另一侧，也没有固定分辨率上限。
- 实际：
- 结果：通过 / 不通过

### 7. 四边与四角气泡

- 准备：显示一条能在当前显示器内完整展示的推荐气泡。
- 操作：依次把小猫拖到上、下、左、右边界及四个角落。
- 预期：气泡位于相反方向或斜对角，内容一次完整显示，不滚动、不压缩字号。
- 实际：
- 结果：通过 / 不通过

### 8. 小猫位置锚定

- 预期：气泡大小或方向变化时小猫不漂移；拖动落点与鼠标一致。

- 结果：通过 / 不通过

- 预期：没有仅剩 1～2 个字符的末行，没有结束标点出现在行首，文字不覆盖按钮。

- 结果：通过 / 不通过
